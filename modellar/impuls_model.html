🎱 Impulsning Saqlanish Qonuni

Aravachalar to'qnashuvi: m₁v₁ + m₂v₂ = m₁v₁′ + m₂v₂′

🎯 Topshiriq

  1. «Elastik», m₁ = m₂ = 1.0 kg, v₁ = +2.0 m/s, v₂ = 0: «Boshlash»ni bosing — aravalar tezliklarini almashtirdimi (v₁′ ≈ 0, v₂′ ≈ 2 m/s)? Natijani jurnalga yozing (S)
  2. Xuddi shu sonlar bilan «Noelastik»: umumiy tezlik 1 m/s chiqdimi? Q = 1 J — boshlang'ich Eₖ ning yarmi issiqlikka aylandimi?
  3. «Elastik», m₂ = 4.0 kg (og'ir nishon): 1-arava orqaga qaytdimi (v₁′ ≈ −1.2 m/s, v₂′ ≈ +0.8 m/s)? p oldin va keyin tengmi?
  4. m₂ = 1.0 kg, «Qisman elastik», k = 0.50: v₁′ ≈ 0.5 m/s, v₂′ ≈ 1.5 m/s va Q = 0.75 J ekanini tekshiring
  5. «Noelastik», m₁ = m₂ = 1 kg, v₁ = +2, v₂ = −2 m/s (qarama-qarshi): aravalar to'xtadimi? Eₖ qancha qismi issiqlikka aylandi, p esa-chi?

⚙️ Sozlamalar

Ishora — yo'nalish: + o'ngga, − chapga.

⚠️ v₁ ≤ v₂ — aravalar bir-biriga yaqinlashmaydi, to'qnashuv bo'lmaydi. 1-arava 2-aravadan tezroq o'ngga harakatlanishi kerak (v₁ > v₂).

📚 Nazariy Ma'lumot

Jismning impulsi (harakat miqdori) — massasining tezligiga ko'paytmasi. Impuls vektor kattalik: uning yo'nalishi tezlik yo'nalishi bilan bir xil, bir o'lchovli harakatda esa ishora bilan beriladi.

p = m·v   [kg·m/s]

Impulsning saqlanish qonuni: berk (yopiq) sistemada, ya'ni tashqi kuchlar ta'sir qilmaganda yoki ularning teng ta'sir etuvchisi nolga teng bo'lganda, jismlar impulslarining vektor yig'indisi o'zaro ta'sirdan oldin va keyin bir xil bo'ladi. Ishqalanishsiz gorizontal yo'lda og'irlik kuchi va tayanch reaksiya kuchi bir-birini muvozanatlaydi, shuning uchun ikki aravacha berk sistema hisoblanadi:

m₁v₁ + m₂v₂ = m₁v₁′ + m₂v₂′

💥 Mutlaq elastik to'qnashuv (prujinali bamper, po'lat sharlar): impuls bilan birga kinetik energiya ham saqlanadi. Ikki tenglamani birga yechsak:

v₁′ = ((m₁ − m₂)·v₁ + 2m₂·v₂) / (m₁ + m₂)
v₂′ = ((m₂ − m₁)·v₂ + 2m₁·v₁) / (m₁ + m₂)

Massalar teng bo'lsa (m₁ = m₂) aravalar tezliklarini almashadi. Og'ir nishonga (m₂ > m₁) urilgan yengil arava orqaga qaytadi: m₁ = 1 kg, m₂ = 4 kg, v₁ = 2 m/s, v₂ = 0 da v₁′ = −1.2 m/s, v₂′ = +0.8 m/s.

🧲 Mutlaq noelastik to'qnashuv (plastilin, «yopishqoq lenta»): jismlar yopishib, bitta umumiy tezlik bilan harakatlanadi. Impuls saqlanadi, kinetik energiyaning bir qismi esa deformatsiya va ichki energiyaga (issiqlikka) aylanadi:

v′ = (m₁v₁ + m₂v₂) / (m₁ + m₂)
Q = Eₖ − Eₖ′ = m₁m₂·(v₁ − v₂)² / (2(m₁ + m₂))

Masalan, m₁ = m₂ = 1 kg, v₁ = 2 m/s, v₂ = 0 da v′ = 1 m/s, Eₖ = 2 J dan Eₖ′ = 1 J qoladi — energiyaning yarmi issiqlikka aylanadi. Qarama-qarshi tomondan bir xil tezlikda kelgan teng aravalar to'xtab qoladi: impuls nolga teng edi va nol bo'lib qoladi, lekin butun kinetik energiya issiqlikka aylanadi.

⚖️ Qisman elastik to'qnashuv: real jismlar oraliq holatda bo'ladi. Uni tiklanish koeffitsiyenti k bilan tavsiflash qulay — ajralish tezligining yaqinlashish tezligiga nisbati (k = 1 — elastik, k = 0 — noelastik):

k = (v₂′ − v₁′) / (v₁ − v₂),   Q = (1 − k²)·m₁m₂·(v₁ − v₂)² / (2(m₁ + m₂))

📏 O'lchash: modelda to'qnashuvdan keyingi tezliklar formuladan ko'chirilmaydi — aravaning to'qnashuv paytidagi va hozirgi koordinatalari bo'yicha v′ = Δx/Δt sifatida o'lchanadi. To'qnashuv paytining o'zi ham kadrlar orasida analitik aniqlanadi, shuning uchun aravalar bir-biridan «o'tib ketmaydi». Biror arava yo'l chetidagi to'xtatgichga yetganda tajriba tugaydi.
